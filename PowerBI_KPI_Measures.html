Power BI KPI Measures

Sales comparison measures — Last Year, Last Month & Conditional Formatting

Copy tip: Drag-select any DAX code below and press Ctrl + C, or use the Copy button.
1. KPI Card — vs Last Year
Calculates Sales percentage change compared with the previous year.
KPI Card =

VAR _CM = [Sales]

VAR _PM =
    CALCULATE(
        [Sales],
        DATEADD('Date Table'[Date], -1, YEAR)
    )

VAR _perc =
    DIVIDE(_CM - _PM, _PM)

VAR _format =
    SWITCH(
        TRUE(),
        _perc > 0, UNICHAR(11165) & " " & FORMAT(_perc, "0.0%"),
        _perc < 0, UNICHAR(11167) & " " & FORMAT(_perc * -1, "0.0%"),
        FORMAT(_perc, "0.0%")
    )

RETURN
    _format
